Install

npm install @logimaxx/kviews.js handlebars jquery

Quick start (ES modules)

KViews expects jQuery and Handlebars as peer dependencies (globals in the browser, or configured in your bundler) before you call the API. 

import KViews from '@logimaxx/kviews.js';

KViews.createCollectionInstance('#posts', {
  url: '/api/posts',
  type: 'posts',
});

Bundle (no bundler)

On this site, the built files are served from ./dist/ after each deploy. In your own app you can load from npm/CDN instead. 

<script src="path/to/jquery.min.js"></script>
<script src="path/to/handlebars.min.js"></script>
<script src="path/to/kviews.min.js"></script>
